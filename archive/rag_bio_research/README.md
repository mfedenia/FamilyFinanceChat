# Archived RAG research notebooks

These five notebooks are preserved unchanged as historical research, not a
supported retrieval service. Their old paths, imports and stored outputs describe
the retired ChromaDB experiment and are not current setup instructions.

The four `notebooks/` files came from `rag_bio_project/notebooks/`; the training
notebook came from `rag_bio_project/training_testing_pipeline/`.
Dependencies and generated indexes are intentionally not maintained here. To
reproduce the historical experiment, use an isolated checkout of `cebf04a0a2de17752fb6ba154a777db385f8c115`.
Do not connect that checkout to production credentials or data.

See [A22 decision](../../docs/decisions/a22-retrieval.md). The canonical production
retrieval path is Open WebUI Knowledge Bases backed by Qdrant.
